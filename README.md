# DEU CAPA — Revista Digital

**Quem acontece, aparece.**

DEU CAPA é uma revista digital interativa voltada para matérias, talentos, marcas, eventos, galerias e edições especiais, com experiência editorial adaptada para celular, tablet e computador.

## Projeto

Esta é a base oficial da revista **DEU CAPA**, construída com Next.js/React sobre Vinext e preparada para evolução como aplicação full-stack.

### Áreas principais

- Home editorial
- Matérias e artigos
- Categorias
- Galeria de fotos
- Agenda e eventos
- Edições da revista
- Editorial
- Área “Divulgue”
- Painel administrativo
- APIs internas
- Estrutura de banco com Drizzle

## Desenvolvimento

Requisitos:

- Node.js `>=22.13.0`
- npm

Comandos principais:

```bash
npm ci
npm run dev
```

Para validação da aplicação:

```bash
npm run build
npm test
```

## Estrutura

- `app/` — páginas, componentes, painel e rotas da aplicação
- `app/api/` — APIs
- `db/` — acesso e estrutura de dados
- `drizzle/` — migrações
- `public/` — arquivos públicos
- `scripts/` — scripts de desenvolvimento e build

## Deploy

Por enquanto o projeto permanece no GitHub durante a fase de desenvolvimento. O deploy público definitivo será configurado quando a revista estiver pronta para produção.
