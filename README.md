# TOPS Revista Digital

Plataforma editorial demonstrativa com site público, revista folheável, matérias, ranking, eventos e painel administrativo.

## Como executar

Abra `index.html` em um navegador moderno ou publique a pasta em uma hospedagem estática.

## Painel administrativo

Abra `admin.html`. Nesta versão, as alterações são salvas no navegador usando localStorage.

## Observação

A próxima fase deve conectar autenticação, banco de dados e armazenamento online para sincronização entre dispositivos.
